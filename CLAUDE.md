# CLAUDE.md

## MANDATORY: Change control (SOC 2 CC8.1)

- Never commit or push to `main`. Work on a branch `<developer>/<topic>`.
- Commit as the developer running this session (their own git identity).
- Open a pull request when the work is ready; fill the PR template with tests run.
- Never approve, merge, or bypass a ruleset. A human other than the author approves.
